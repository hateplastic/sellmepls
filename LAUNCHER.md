# Локальный запуск

Дважды нажмите **Sellmepls Launcher.exe** в папке проекта. Он запустит Next.js и обработчик подтверждений платежей, затем откроет http://localhost:3000 в браузере по умолчанию. Для входа используйте браузер с установленным кошельком.

- Оставьте окно лаунчера открытым, пока пользуетесь сайтом. «Остановить» или закрытие окна завершают только запущенные им процессы, включая дочерние процессы Next.js.
- Если сайт уже запущен отдельно, лаунчер откроет его, но не будет останавливать чужой сервер или запускать второй обработчик оплат.
- Кнопка «Показать логи» открывает папку `logs`. Первый запуск страницы может занять дольше из-за компиляции.
- EXE должен оставаться рядом с `package.json`, `.env.local`, `node_modules` и исходниками. Это лаунчер установленного проекта, а не переносимый сервер со встроенной базой данных. Node.js должен быть установлен.
- Сайт слушает только локальный адрес. Supabase, R2 и RPC требуют интернета. Mainnet остаётся mainnet: запуск на localhost не превращает реальные монеты в тестовые.
- Не меняйте порт произвольно: `NEXT_PUBLIC_APP_URL` и настройки входа кошельком рассчитаны на localhost:3000.

Исходник: `launcher/SellmeplsLauncher.cs`. Пересборка: `powershell -File launcher/build.ps1`.
